# WordListBack
Embaraçador de nomes, letras, números, caracteres, etc. Para a criação de wordlist ou lista de senhas.
![DooodtaSet](https://user-images.githubusercontent.com/25424970/168957389-e1b4a1f1-3f36-4c84-bfe0-69dee5da9e6c.png)
<b>Versão: </b>0.4

# Mais sobre WordListBack
Uma lista de palavras pode conter ate 8 combinações que voce pode utilizar
na criação de suas senhas. Na opção Hard voce esta sujeito a ter uma senha
muito grande entao utilize as melhores palavaras ou não obterar o resultado
esperado fazendo isso voce pode usar mais letras para que sua lista de senhas
seja mais afundo na possivel senha que voce deseja obter, utilize frazes
pequenas para que suas senhas não fique muito grandes.

# Modo de usar:
- wget https://raw.githubusercontent.com/CyberKR740/WordListBack/main/.WordListBack.py
